Data source

The Apps Script Web App URL for your league's Google Sheet (Deploy > Manage deployments > copy the URL ending in /exec).

Passcode

The admin passcode unlocks everything on this browser. The scorekeeper passcode (optional) only records games: Log Game, Live and bracket scores. Both are set in Apps Script (Project Settings > Script Properties: ADMIN_PASSCODE and SCORER_PASSCODE) and checked there for every change.

Rating model

Rebuild every player's rating from the complete game history using the current global model. Run this once after deploying a rating-algorithm update. Requires the admin passcode above.

League name

Shown in the banner at the top of every page. Saved to your Google Sheet's Apps Script project, so it's the same for everyone — not just this browser. Requires the admin passcode above.

DUPR estimate

If someone in the league has a real DUPR, pick them and enter it here. Every DUPR est. on the Leaderboard then lines up to that rating, for everyone. Requires the admin passcode above.
